## 问题

公网调用车场信息接口，返回的数据列表是空的。用同一个车场编号在常用的库里能查到记录。

## 卡点

空列表是「这次查询的结果集行数为 0」。它不区分「过滤条件把行丢掉了」和「连的库里根本没有这行」。本地曾经对同一编号返回过数据，只能说明那次进程的数据源里有行。

公网进程的 JDBC 地址、库名可以和手工客户端不同。在错误的库上重复同一条 SQL，会得到有数据的结论，和接口看到的不是同一次查询。

## 解决思路

在应用进程配置里写的那个主机、端口和库上再查。对上之后结果仍为空，再看 SQL 条件。对不上，先改连接，不改语句。

## 关键位置

对外车场信息接口。数据源看运行中的进程配置，不看仓库里的示例地址。

## 以后怎么用

线上空、线下有，先把两边的 JDBC URL 打出来比库名。同一条 SQL 只有在同一个连接上执行，结果才能互相解释。
